# Math Pattern-Wise Problem Index — Codeforces 800 → 1900

> **Goal:** build mathematical modeling speed the same way as the Prefix Sum forms sheet: learn one form, solve **3–5 representative problems**, then mix forms in contests.
>
> Problems are arranged **inside each form from easier → harder**. Ratings are Codeforces ratings and may occasionally be re-rated by Codeforces.

---

# How to Use This Sheet

```text
For each form:

1. Learn the mathematical model
2. Solve first 3 problems without editorial
3. Solve 1–2 stretch problems
4. Write the one-line recognition clue
5. Move to mixed A/B/C practice
```

**Suggested progression:**

| Phase | Rating | Target |
|---|---:|---|
| Foundation | 800–1000 | Translate story → equation quickly |
| Modeling | 1100–1300 | Recognize parity/GCD/modulo/pair transforms |
| Combined | 1400–1600 | Combine math with sorting/hash/sieve |
| Advanced | 1700–1900 | Factorization, normalization, counting structure |

# Rating Coverage

The sheet intentionally spans the full target range:

```text
800–1000  → direct math + basic modeling
1100–1300 → transformation + GCD/modulo/pairs
1400–1600 → combined techniques
1700–1800 → deeper number-theory structure
1900      → advanced normalization/counting
```

# Final Recognition Map

| If the statement says / looks like... | First math model to test |
|---|---|
| operations needed to reach target | equation / ceil division |
| distance / balance / equalize | difference / absolute difference |
| at most / at least / possible range | inequality / bounds |
| odd / even | parity |
| divisible / remainder | modulo |
| common step / shared divisor | GCD |
| repeating multiples / minimize common multiple | LCM |
| prime copies / split product | factorization + exponents |
| factors of `n` | divisor enumeration to `sqrt(n)` |
| pair relation `a[j]-a[i]=...` | rearrange → common key |
| operations preserve some property | invariant / normalization |
| repeated division / rounded count | floor / ceil / quotient |
| print any valid numbers | constructive math |
| many primality/factor queries | sieve / SPF |
| coprime / same GCD | totient / divisor-count model |
| exponent parity / square-free state | multiplicative normalization |
| every item appears many times | contribution counting |

> **Core contest habit:** `WORDS → VARIABLES → EQUATION/INVARIANT → PATTERN → ALGORITHM`.
