# BFS Foundations — Level Order, Unweighted SSSP & Grid BFS

> **Goal:** understand BFS as a graph traversal that explores nodes **level by level**, then use that property for **shortest path in an unweighted graph** and **grid shortest path**.

```text
DFS → go deep first
BFS → go level by level

BFS + distance array
        ↓
shortest number of edges from source
```

# 1. What BFS Is

BFS means:

```text
Breadth First Search
```

It explores a graph **breadth-wise**:

```text
source
  ↓
all nodes 1 edge away
  ↓
all nodes 2 edges away
  ↓
all nodes 3 edges away
  ↓
...
```

This is the key difference from DFS.

---

# 2. Prerequisite — Graph Representation

For a normal explicit graph, use an adjacency list.

Example:

```text
1 -- 2
|    |
3 -- 4 -- 5
```

Adjacency list:

```text
1 → [2,3]
2 → [1,4]
3 → [1,4]
4 → [2,3,5]
5 → [4]
```

C++:

```cpp
vector<vector<int>> g(n + 1);

for (int i = 0; i < m; i++) {
    int a, b;
    cin >> a >> b;

    g[a].push_back(b);
    g[b].push_back(a);
}
```

For an undirected edge:

```text
a -- b
```

store both directions.

---

# 3. Prerequisite — Queue

BFS uses a **queue**.

Queue rule:

```text
FIFO
=
First In, First Out
```

Example:

```text
push 1
push 2
push 8
push 3
push 4
push 7

front
 ↓
[1, 2, 8, 3, 4, 7]
                   ↑
                  back
```

Removal order:

```text
1 → 2 → 8 → 3 → 4 → 7
```

C++:

```cpp
queue<int> q;

q.push(5);

int node = q.front();
q.pop();
```

Important operations:

```text
q.push(x)   → insert at back
q.front()   → read front
q.pop()     → remove front
q.empty()   → check if empty
```

# 4. DFS vs BFS

Consider:

```text
        (1)
       /   \
     (2)   (8)
    /  \     \
  (3)  (4)   (7)
       / \
     (5) (6)
```

A possible DFS order:

```text
1 → 2 → 3 → 4 → 5 → 6 → 8 → 7
```

DFS follows one branch deeply.

BFS groups nodes by distance from the source:

```text
Level 0: 1
Level 1: 2, 8
Level 2: 3, 4, 7
Level 3: 5, 6
```

Possible BFS order:

```text
1 → 2 → 8 → 3 → 4 → 7 → 5 → 6
```

The exact order inside one level can vary with adjacency-list order.

The important guarantee is:

```text
all distance d nodes are processed
before any distance d+1 node
```

# 5. BFS Level-by-Level

Graph:

```text
            (1)
          /     \
        (2)     (8)
       /   \      \
     (3)   (4)    (7)
           |
          (5)
```

Start:

```text
Distance 0
    (1)
```

After processing 1:

```text
Distance 1

   (2)     (8)
```

Then:

```text
Distance 2

 (3)   (4)   (7)
```

Then:

```text
Distance 3

      (5)
```

This is why BFS naturally gives shortest edge-count distances.

# 6. Basic BFS Algorithm

```text
BFS(source)

1. create queue
2. mark source visited
3. push source

4. while queue not empty:
      node = queue.front
      pop node

      for every neighbor:
          if neighbor not visited:
              mark visited
              push neighbor
```

Pseudocode:

```text
visited[source] = true
queue.push(source)

while queue not empty:
    node = queue.front()
    queue.pop()

    for neighbor of node:
        if neighbor not visited:
            visited[neighbor] = true
            queue.push(neighbor)
```

---

# 7. Why Mark Visited Before Pushing

Consider:

```text
       (1)
      /   \
    (2)---(3)
```

From 1:

```text
queue = [2,3]
```

Later 2 sees 3, and 3 sees 2.

If we delay marking visited, the same node may enter the queue repeatedly.

Correct:

```cpp
if (!visited[neighbor]) {
    visited[neighbor] = 1;
    q.push(neighbor);
}
```

Rule:

```text
MARK VISITED
before
PUSH INTO QUEUE
```

Then every vertex enters the queue at most once.

# 8. BFS Dry Run

Graph:

```text
        (1)
       /   \
     (2)   (3)
    / \      \
  (4) (5)    (6)
```

Start from `1`.

Initial:

```text
visited[1] = true
queue = [1]
```

Compact dry run:

```text
Step 1: pop 1 → discover 2,3 → queue=[2,3]
Step 2: pop 2 → discover 4,5 → queue=[3,4,5]
Step 3: pop 3 → discover 6   → queue=[4,5,6]
Step 4: pop 4 → no new node  → queue=[5,6]
Step 5: pop 5 → no new node  → queue=[6]
Step 6: pop 6 → no new node  → queue=[]
```

Traversal:

```text
1, 2, 3, 4, 5, 6
```

Levels:

```text
0: 1
1: 2,3
2: 4,5,6
```

# 9. Basic C++17 BFS

```cpp
#include <bits/stdc++.h>
using namespace std;

int n, m;
vector<vector<int>> g;
vector<int> visited;

void bfs(int source) {
    queue<int> q;

    visited[source] = 1;
    q.push(source);

    while (!q.empty()) {
        int node = q.front();
        q.pop();

        for (int neighbor : g[node]) {
            if (!visited[neighbor]) {
                visited[neighbor] = 1;
                q.push(neighbor);
            }
        }
    }
}

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    cin >> n >> m;

    g.resize(n + 1);

    for (int i = 0; i < m; i++) {
        int a, b;
        cin >> a >> b;

        g[a].push_back(b);
        g[b].push_back(a);
    }

    visited.assign(n + 1, 0);

    bfs(1);

    return 0;
}
```

# 10. Distance Array

Add:

```text
dist[node]
```

Meaning:

```text
minimum number of edges
from source to node
```

Initialize:

```text
dist[source] = 0
```

If BFS moves:

```text
node → neighbor
```

then:

```text
dist[neighbor] = dist[node] + 1
```

Example:

```text
        (1)
       /   \
     (2)   (3)
    /       \
  (4)       (5)
```

From source `1`:

```text
dist[1] = 0
dist[2] = 1
dist[3] = 1
dist[4] = 2
dist[5] = 2
```

# 11. Why BFS Gives Shortest Path

Assume every edge costs exactly one move.

BFS processes:

```text
distance 0
before
distance 1

then distance 1
before
distance 2

then distance 2
before
distance 3
```

Therefore when a node is discovered for the first time, BFS has reached it using the minimum possible number of edges.

If a shorter route existed, that route would have come from an earlier BFS level.

So:

```text
first discovery
=
shortest edge count
```

Use BFS for:

```text
unweighted graph
or
all edges having equal cost
```

# 12. SSSP — Single Source Shortest Path

SSSP means:

```text
Single Source Shortest Path
```

Problem:

```text
Given one source S,
find shortest distance from S
to every reachable node.
```

Example:

```text
             (1)
           /     \
         (2)     (3)
        /       /   \
      (4)     (5)   (6)
```

Source:

```text
S = 1
```

Distances:

```text
1 → 0
2 → 1
3 → 1
4 → 2
5 → 2
6 → 2
```

This is exactly what BFS computes in an unweighted graph.

# 13. BFS with Distance

```cpp
#include <bits/stdc++.h>
using namespace std;

const int INF = 1e9;

int n, m;
vector<vector<int>> g;
vector<int> dist;

void bfs(int source) {
    queue<int> q;

    dist.assign(n + 1, INF);
    dist[source] = 0;
    q.push(source);

    while (!q.empty()) {
        int node = q.front();
        q.pop();

        for (int neighbor : g[node]) {
            if (dist[neighbor] == INF) {
                dist[neighbor] = dist[node] + 1;
                q.push(neighbor);
            }
        }
    }
}
```

Notice:

```text
dist[node] == INF
```

also works as the unvisited condition.

So a separate `visited` array is not necessary here.

# 14. Parent Array & Path Reconstruction

Distance tells:

```text
how far?
```

But sometimes we need:

```text
what actual shortest path?
```

Store:

```text
parent[node]
```

When BFS discovers:

```text
node → neighbor
```

set:

```cpp
parent[neighbor] = node;
```

Example shortest path:

```text
1 → 2 → 4 → 7
```

Parents:

```text
parent[7] = 4
parent[4] = 2
parent[2] = 1
parent[1] = -1
```

Rebuild from destination:

```text
7 → 4 → 2 → 1
```

Reverse:

```text
1 → 2 → 4 → 7
```

# 15. Complete Graph BFS + Path

```cpp
#include <bits/stdc++.h>
using namespace std;

const int INF = 1e9;

int n, m;
vector<vector<int>> g;
vector<int> dist;
vector<int> parent;

void bfs(int source) {
    dist.assign(n + 1, INF);
    parent.assign(n + 1, -1);

    queue<int> q;

    dist[source] = 0;
    q.push(source);

    while (!q.empty()) {
        int node = q.front();
        q.pop();

        for (int neighbor : g[node]) {
            if (dist[neighbor] == INF) {
                dist[neighbor] = dist[node] + 1;
                parent[neighbor] = node;
                q.push(neighbor);
            }
        }
    }
}

vector<int> buildPath(int destination) {
    vector<int> path;

    if (dist[destination] == INF) {
        return path;
    }

    int current = destination;

    while (current != -1) {
        path.push_back(current);
        current = parent[current];
    }

    reverse(path.begin(), path.end());
    return path;
}

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    cin >> n >> m;

    g.resize(n + 1);

    for (int i = 0; i < m; i++) {
        int a, b;
        cin >> a >> b;

        g[a].push_back(b);
        g[b].push_back(a);
    }

    int source, destination;
    cin >> source >> destination;

    bfs(source);

    if (dist[destination] == INF) {
        cout << "Not reachable\n";
        return 0;
    }

    cout << "Distance = " << dist[destination] << '\n';

    vector<int> path = buildPath(destination);

    for (int node : path) {
        cout << node << ' ';
    }

    cout << '\n';
    return 0;
}
```

# 16. Grid as an Implicit Graph

The lecture then moves from a normal graph to a grid.

Example:

```text
S . # . .
. . # . .
# . # . #
. . . . #
# # # # .
F . . . .
```

Where:

```text
S = start
F = finish
# = wall
. = free cell
```

The grid is still a graph.

Model:

```text
each valid cell = vertex
valid move between cells = edge
```

So:

```text
Grid
 ↓
Implicit Graph
```

We do not receive an explicit edge list.

We generate neighbors from movement rules.

```text
5
```

```text
(row, column)
```

Example:

```text
(2,3)
```

```cpp
using State = pair<int, int>;
```

# 18. Four-Direction Movement

Standard 4-direction movement:

```text
       UP
        ↑
LEFT ← cell → RIGHT
        ↓
      DOWN
```

Coordinate changes:

```text
up    = (-1, 0)
right = ( 0, 1)
down  = ( 1, 0)
left  = ( 0,-1)
```

Compact arrays:

```cpp
int dx[] = {-1, 0, 1, 0};
int dy[] = {0, 1, 0, -1};
```

Neighbor `k`:

```cpp
int nx = x + dx[k];
int ny = y + dy[k];
```

---

# 19. Validity Function

Before moving into `(x,y)`, check:

```text
1. row is inside grid
2. column is inside grid
3. cell is not a wall
```

Mathematically:

```text
0 ≤ x < n
0 ≤ y < m
grid[x][y] != '#'
```

C++:

```cpp
bool isValid(int x, int y) {
    return x >= 0 && x < n &&
           y >= 0 && y < m &&
           grid[x][y] != '#';
}
```

This function decides whether an implicit edge exists.

# 20. Generating Neighbors

Normal graph:

```cpp
for (int neighbor : g[node]) {
    ...
}
```

Grid graph:

```cpp
for (int k = 0; k < 4; k++) {
    int nx = x + dx[k];
    int ny = y + dy[k];

    if (isValid(nx, ny)) {
        ...
    }
}
```

So instead of storing an adjacency list for each cell, generate neighbors on demand.

```text
current cell
    ↓
try 4 moves
    ↓
reject invalid/wall cells
    ↓
remaining cells are neighbors
```

# 21. Grid BFS Dry Run

Example:

```text
S . # .
. . # .
# . . .
. . # F
```

Let:

```text
S = (0,0)
F = (3,3)
```

Start:

```text
dist[0][0] = 0
queue = [(0,0)]
```

From `(0,0)`:

```text
up    → outside
right → (0,1) valid
down  → (1,0) valid
left  → outside
```

Therefore:

```text
dist[0][1] = 1
dist[1][0] = 1
```

Queue:

```text
[(0,1), (1,0)]
```

Then BFS expands all distance-1 cells before any distance-2 cell.

That is exactly the same BFS rule as in a normal graph.

# 22. Grid BFS C++17

```cpp
#include <bits/stdc++.h>
using namespace std;

using State = pair<int, int>;

const int INF = 1e9;

int n, m;
vector<string> grid;
vector<vector<int>> dist;

int dx[] = {-1, 0, 1, 0};
int dy[] = {0, 1, 0, -1};

bool isValid(int x, int y) {
    return x >= 0 && x < n &&
           y >= 0 && y < m &&
           grid[x][y] != '#';
}

void bfs(State start) {
    dist.assign(n, vector<int>(m, INF));

    queue<State> q;

    dist[start.first][start.second] = 0;
    q.push(start);

    while (!q.empty()) {
        auto [x, y] = q.front();
        q.pop();

        for (int k = 0; k < 4; k++) {
            int nx = x + dx[k];
            int ny = y + dy[k];

            if (isValid(nx, ny) && dist[nx][ny] == INF) {
                dist[nx][ny] = dist[x][y] + 1;
                q.push({nx, ny});
            }
        }
    }
}

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    cin >> n >> m;

    grid.resize(n);

    State start = {-1, -1};
    State finish = {-1, -1};

    for (int i = 0; i < n; i++) {
        cin >> grid[i];

        for (int j = 0; j < m; j++) {
            if (grid[i][j] == 'S') {
                start = {i, j};
            }

            if (grid[i][j] == 'F') {
                finish = {i, j};
            }
        }
    }

    bfs(start);

    int answer = dist[finish.first][finish.second];

    if (answer == INF) {
        cout << "Finish is not reachable\n";
    } else {
        cout << answer << '\n';
    }

    return 0;
}
```

# 23. Grid Path Reconstruction

Store previous cell:

```cpp
vector<vector<State>> parent;
```

When moving:

```text
(x,y) → (nx,ny)
```

save:

```cpp
parent[nx][ny] = {x, y};
```

Then reconstruct backward from finish.

```text
F
↑
cell
↑
cell
↑
S
```

Reverse to obtain:

```text
S → ... → F
```

Core modification:

```cpp
parent.assign(n, vector<State>(m, {-1, -1}));
```

Inside BFS:

```cpp
if (isValid(nx, ny) && dist[nx][ny] == INF) {
    dist[nx][ny] = dist[x][y] + 1;
    parent[nx][ny] = {x, y};
    q.push({nx, ny});
}
```

Reconstruction:

```cpp
vector<State> buildPath(State start, State finish) {
    vector<State> path;

    if (dist[finish.first][finish.second] == INF) {
        return path;
    }

    State current = finish;

    while (current != State{-1, -1}) {
        path.push_back(current);

        if (current == start) {
            break;
        }

        current = parent[current.first][current.second];
    }

    reverse(path.begin(), path.end());
    return path;
}
```

# 24. Complexity

## Normal Graph

Let:

```text
V = vertices
E = edges
```

Each vertex enters the queue at most once.

Each edge is inspected a constant number of times.

Therefore:

```text
Time   = O(V + E)
Memory = O(V + E)
```

---

## Grid

For an `N × M` grid:

```text
V = N × M
```

Each cell has at most 4 neighbors.

So:

```text
E = O(4NM) = O(NM)
```

Therefore:

```text
Time   = O(NM)
Memory = O(NM)
```

This is just the grid form of:

```text
O(V + E)
```

# 25. Common Mistakes

## Mistake 1 — Using DFS for shortest path

DFS finds a path but does not guarantee the shortest path in an unweighted graph.

Use:

```text
BFS
```

---

## Mistake 2 — Marking visited too late

Correct:

```cpp
visited[neighbor] = 1;
q.push(neighbor);
```

Do not wait until the node is popped.

---

## Mistake 3 — Forgetting `INF`

For distance BFS:

```cpp
dist.assign(n + 1, INF);
```

or grid:

```cpp
dist.assign(n, vector<int>(m, INF));
```

---

## Mistake 4 — Wrong grid bounds

Correct:

```text
0 <= x < n
0 <= y < m
```

---

## Mistake 5 — Walking through walls

Check:

```cpp
grid[x][y] != '#'
```

---

## Mistake 6 — Mixing row and column

Keep one convention:

```text
x = row
y = column
```

Then:

```text
0 <= x < n
0 <= y < m
```

---

## Mistake 7 — Printing INF as an answer

If:

```text
dist[target] == INF
```

then target is unreachable.

---

## Mistake 8 — Using BFS for arbitrary weighted edges

This shortest-path guarantee is for:

```text
unweighted graph
or equal edge weights
```

# 26. Recognition Checklist

Ask:

```text
1. Is there a graph or implicit graph?

2. Does every move cost the same?

3. Is the problem asking minimum:
   • edges?
   • moves?
   • steps?

4. Is there one source?

5. Do I need only distance?
   or the actual path too?

6. Is the state:
   • normal node
   • grid cell (x,y)
```

Recognition map:

```text
Visit reachable nodes
        ↓
BFS or DFS

Visit level by level
        ↓
BFS

Shortest path in unweighted graph
        ↓
BFS + dist

Need actual shortest path
        ↓
BFS + parent

Grid shortest path
        ↓
cell = node
valid move = edge
BFS on implicit graph
```

# 27. Final Mental Model

```text
STEP 1 — BFS traversal

queue
visited
```

Then:

```text
STEP 2 — shortest distance

dist[neighbor] = dist[node] + 1
```

Then:

```text
STEP 3 — actual shortest path

parent[neighbor] = node
```

Then generalize to grid:

```text
STEP 4 — implicit graph

node = (x,y)

neighbor =
(x + dx[k], y + dy[k])
```

Full picture:

```text
                BFS
                 |
        +--------+--------+
        |                 |
   Explicit Graph     Implicit Graph
        |                 |
 adjacency list           grid
        |                 |
        +--------+--------+
                 |
            queue traversal
                 |
          distance by levels
                 |
      shortest path in unweighted graph
```

Most important recognition rule:

```text
If every move costs 1
and the problem asks minimum number of moves/edges,

think BFS.
```
