> **Goal:** recognize the hidden mathematical form without being told the pattern.

```text
STATEMENT → REMOVE STORY → VARIABLES → CONDITION / EQUATION → RECOGNIZE FORM
```

## How to Use

Before coding each problem, write:

```text
1. Variables:
2. Core condition / equation:
3. Mathematical form:
4. Key observation / transformation:
```

Do not check the answer key until you have attempted recognition.

## Recognition Checklist

| Statement signal | Recognition question |
|---|---|
| minimum operations / maximum change per move | Ceil division or operation equation? |
| at least / at most | Bound or inequality? |
| odd / even | Can the state collapse to parity? |
| divisible / common divisor | Divisibility, GCD, or LCM? |
| repeating / cyclic | Is modulo the real state? |
| count pairs | Can the pair relation become equal keys/frequencies? |
| many range queries | Prefix algebra? |
| repeated operation | What is the delta? What is invariant? |
| construct any valid answer | Constructive feasibility? |
| XOR / AND / bits | Cancellation or independent bits? |
| positions / sorted values / distance | Ordering or distance transformation? |
| monotonic feasibility | Boundary / binary-search form? |
